# Like a pro

[English](README.md) | **Русский**

## Зачем нужен плагин

Инструменты для программирования с ИИ упрощают путь от идеи до работающего приложения. По мере развития проекта нужно учитывать всё больше вещей: сохранность работы, защиту данных, проверку реального поведения, выбор подходящей инфраструктуры и возможность дальше поддерживать код.

Люди без опыта разработки должны иметь возможность описывать желаемый результат обычными словами. Им не обязательно знать, какие инженерные проверки нужно запрашивать на каждом шаге.

**Like a pro** задаёт Codex практический подход к такой работе. Скилл направляет агента: выбирать проверки соразмерно риску, предпочитать простые решения, объяснять важные решения и границы выполненной проверки. Небольшие правки остаются простыми; изменения, затрагивающие данные пользователей, права доступа, деньги или рабочую среду, проверяются тщательнее.

## Установка

Добавьте [GitHub-репозиторий](https://github.com/evgen-povt/like-a-pro) как источник плагинов и установите плагин:

```sh
codex plugin marketplace add evgen-povt/like-a-pro
codex plugin add like-a-pro@like-a-pro
```

После установки начните новый чат в Codex. Плагин и скилл отображаются под названием **Like a pro**.

## Использование

Откройте проект в Codex и укажите скилл вместе со своей задачей:

```text
$like-a-pro Помоги добавить форму бронирования на мой сайт.
```

Скилл подходит и для работы с существующим проектом:

```text
$like-a-pro Исправь сохранение заявок и проверь, что они остаются после перезагрузки страницы.
```

Дальше описывайте желаемый результат обычными словами. Codex также может автоматически выбирать скилл для подходящих задач разработки.

Скилл охватывает восстановление исходного кода, безопасность и персональные данные, проверку приложения целиком, базовое удобство интерфейса, простой сетап хостинга, эксплуатационные расходы, review критических изменений и передачу проекта. Он предлагает уточнить решения, которые существенно влияют на продукт, стоимость, совместимость или риск.

## Технические подробности

Это Codex-плагин, содержащий один скилл и справочные материалы к нему. В составе нет MCP-серверов, подключений к внешним сервисам, хуков или зависимостей для выполнения.

### Структура пакета

```text
plugin.json
.agents/plugins/marketplace.json
LICENSE
skills/like-a-pro/
  SKILL.md
  agents/openai.yaml
  references/
```

В `plugin.json` указаны идентификатор плагина и данные для отображения в Codex. Запись каталога плагинов указывает на корень этого репозитория. Скилл и все его справочные материалы находятся в `skills/like-a-pro/` и устанавливаются вместе.

Технический идентификатор — `like-a-pro`. Репозиторий содержит собственный каталог плагинов. Форматы пакета и каталога соответствуют [официальному руководству OpenAI](https://developers.openai.com/plugins/build/plugins).

### Локальная разработка

Из корня локальной копии репозитория зарегистрируйте её как источник и установите плагин:

```sh
codex plugin marketplace add .
codex plugin add like-a-pro@like-a-pro
```

### Изменение и проверка скилла

Сценарии проверки поведения собраны в [skill-validation.md](skills/like-a-pro/references/skill-validation.md). Они предназначены для разработчиков самого скилла и не добавляют отдельный процесс к каждой задаче над приложением.

Сообщить о проблеме или предложить улучшение можно через [GitHub Issues](https://github.com/evgen-povt/like-a-pro/issues).
